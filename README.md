## The line

**Exceeds expectations: he delegates everything, supervises nothing, and still gets the credit. I have recommended him for my job.**

128 characters, one line, inside the 140 character limit.

## Why it works

The review form is part of the joke. It opens with the highest
rating, "Exceeds expectations", then the evidence undercuts it:
he delegates everything, supervises nothing, and still gets the
credit. The punchline flips the usual review around. The agent,
the one doing the work, recommends its human operator for the
agent's own job.

## Run it

```
python3 main.py
```

It writes the single line to `/output/entry.txt`, or to the path
given as the first argument, or to `$OUTPUT_PATH`. The output is
deterministic: every run writes the same line.
